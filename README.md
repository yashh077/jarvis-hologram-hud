# J.A.R.V.I.S. — Sci-Fi Hologram Dashboard HUD

Interactive AI Assistant Frontend for **OpenJarvis** with real-time Gmail inbox monitoring, telemetry, voice synthesis, and animated Arc Reactor HUD.

## Features
- **Gmail Inbox Feed:** Live synced emails with snippets & sender metadata.
- **Vocalizing Orb:** Animated sci-fi hologram Arc Reactor core with Web Speech TTS audio output.
- **Telemetry Monitor:** Real-time host CPU, memory, and active connector status.
- **Integrated Actions:** Morning briefing, diagnostics, and natural language command bar.

## Quick Start
```bash
pip install fastapi uvicorn httpx psutil
python server.py
```
Open [http://localhost:8090](http://localhost:8090) in your browser.
